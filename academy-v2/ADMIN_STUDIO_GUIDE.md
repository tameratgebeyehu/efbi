# EFBI Admin Studio — simple owner guide

Admin Studio runs only on the owner computer. Open it at `http://127.0.0.1:5174` and sign in with the verified EFBI administrator account.

## Main menu

- **Home** — shortcuts to common work.
- **Programs** — edit the learning areas shown on the website.
- **Courses** — create and edit course information.
- **Lessons & videos** — add written lessons, YouTube videos, and practice questions.
- **Publish course** — put one approved course and its lessons online together.
- **Blog** — create and publish articles.
- **Learner reviews** — review submitted projects when a course uses that pathway.
- **Certificates** — manage certificate requests and issued certificates.

Less common operational pages are preserved under **Advanced tools**.

## Add a YouTube video

1. Open **Lessons & videos**.
2. Choose an existing lesson or select **New lesson**.
3. In **YouTube video**, paste either the complete YouTube link or the eleven-character video ID.
4. Wait for **Video recognized**. Admin Studio stores only the safe video ID and removes share-tracking parameters.
5. Add the written lesson. Learners must still be able to learn when YouTube is slow or unavailable.
6. Add up to three practice questions and choose the correct answer for each one.
7. Open the full preview and check the video, text, questions, and answers.
8. Select **Save draft**, then **Mark review ready** when the content is approved.
9. Check the confirmation and publish the lesson.

Supported links include normal watch links, `youtu.be` share links, Shorts, live, embed, and `youtube-nocookie.com` links.

## Publish a complete course

Use this order:

1. Publish its **Program**.
2. Publish its **Course** content.
3. Publish every **Lesson & video** in the correct order.
4. Open **Publish course**.
5. Choose the course and matching published version.
6. Choose **Lessons + practice · no certificate** for AI for Ethiopia.
7. Check the displayed lesson order.
8. Confirm and publish the course.

Publishing does not open learner registration. Keep **Enrollment settings** closed until the separate launch decision.

## Safety and recovery

- Unsaved editor text is copied to local browser storage as you type.
- If electricity or the browser stops, reopen the same editor and choose **Restore copy**.
- Preview before approval and publication.
- Do not place passwords, student records, API keys, or service-account files in content fields.
- Use **Activity history** only when you need to investigate a change.
- Use **Privacy & deletion** only for a real learner request or an isolated test account.
